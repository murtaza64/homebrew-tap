# murtaza64/tap

    brew install murtaza64/tap/pywal

- `wal`: the [pywal fork](https://github.com/murtaza64/pywal) CLI
- `walstudio`: Palette Studio on this machine (http://127.0.0.1:4790/)

The commands run the fork's pinned release through [uv](https://docs.astral.sh/uv/); the first run downloads it. ImageMagick (installed by default) is used for the blurred wallpaper and thumbnails.
